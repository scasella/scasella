## All Projects

### macOS Menu Bar Apps

- [**GhostLabel**](https://github.com/scasella/GhostLabel) — Give Ghostty tabs descriptive titles using Codex. Sends a snapshot of the visible terminal text, or only the working directory and command.
- [**TabPilot**](https://github.com/scasella/TabPilot) — Find duplicate and stale Safari tabs, search open pages, and group tabs by domain. Optional AI grouping runs through a Codex app server; tab titles and URLs go to an OpenAI-hosted model.
- [**SafariMarkdown**](https://github.com/scasella/SafariMarkdown) — Turn the current Safari page into Markdown using Codex. The page's URL, title, and text go to an OpenAI-hosted model.
- [**PasteForge**](https://github.com/scasella/PasteForge) — Reformat, encode, hash, and inspect clipboard text from the menu bar.
- [**ClipDrop**](https://github.com/scasella/ClipDrop) — Opens with the clipboard's text loaded; edit it and save the text with a chosen file type (Markdown, code, JSON, and other text types).
- [**TextDrop**](https://github.com/scasella/TextDrop) — Paste text into a minimal editor and save it as a file; you type the extension in the save dialog.
- [**DiskPulse**](https://github.com/scasella/DiskPulse) — Check used and available space on each connected drive.
- [**PortSentry**](https://github.com/scasella/PortSentry) — See which processes own listening TCP ports and stop them from the menu bar.
- [**ProcessBeacon**](https://github.com/scasella/ProcessBeacon) — Get notified when a long-running process finishes.
- [**BrewPilot**](https://github.com/scasella/BrewPilot) — Start, stop, and restart Homebrew services from the menu bar.
- [**SunShift**](https://github.com/scasella/SunShift) — Adjust Night Shift warmth from the menu bar.

### ML & Research

- [**nanochat-mlx**](https://github.com/scasella/nanochat-mlx) — Train a small chatbot from scratch on Apple Silicon, from tokenizer training to a chat interface. MLX port of nanochat.
- [**gemma4-m4-pro**](https://github.com/scasella/gemma4-m4-pro) — Measured runtime configurations, memory use, and fallback options for Gemma 4 26B A4B on a 24 GB M4 Pro MacBook.
- [**train-gemma4-sudoku-on-your-macbook**](https://github.com/scasella/train-gemma4-sudoku-on-your-macbook) — Run a Sudoku RL notebook for Gemma 4 E2B locally on Apple Silicon. Adapted from Unsloth's notebook.
- [**Proofgrade**](https://github.com/scasella/Proofgrade) — Rubric-based grading of olympiad-style proofs against an official solution, with benchmark results, a CLI, and a local API. Requires a Gemini API key.
- [**society-of-thought-bench**](https://github.com/scasella/society-of-thought-bench) — A preview adapter and synthetic evaluation suite (Countdown, evidence verdicts) for inspecting visible multi-persona reasoning.
- [**hypothesis-forge**](https://github.com/scasella/hypothesis_forge) — An RL environment that scores proposed hypotheses on grounding, novelty, and the experiments that could falsify them.
- [**adaptive-rag-rlm**](https://github.com/scasella/adaptive_rag_rlm) — Test adaptive recursive search against fixed retrieval pipelines on procedurally generated document collections.
- [**ttt-discover-autoresearch-mlx**](https://github.com/scasella/ttt-discover-autoresearch-mlx) — Search for improvements to training code with an RL outer loop, evaluating candidates locally on Apple Silicon. The outer loop needs a Tinker-compatible API key.
- [**autoresearch-evo**](https://github.com/scasella/autoresearch-evo) — Fork of Karpathy's autoresearch that adds run memory, novelty-oriented search, and agent review.

### Distribution

- [**homebrew-tap**](https://github.com/scasella/homebrew-tap) — `brew install scasella/tap/<app>` for ClipDrop, GhostLabel, PasteForge, SafariMarkdown, SunShift, TabPilot, and TextDrop.
